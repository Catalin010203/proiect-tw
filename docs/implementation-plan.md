
# Implementation Plan - Academic Events

## 1. Tehnologii utilizate

**Frontend:**
- HTML5
- CSS3
- JavaScript

**Backend:**
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- Maven

**Baza de date:**
- MySQL

**Instrumente:**
- Git si GitHub pentru versionarea codului.
- Postman pentru testarea API-urilor.
- IntelliJ IDEA pentru dezvoltare.

## 2. Organizarea echipei

- Sandu Catalin: Dezvoltarea backendului, implementarea logicii aplicatiei si conectarea bazei de date.
- Garaba Alexandru: Implementarea autentificarii, autorizarii, rolurilor si functionalitatilor administrative.
- Pasa Nicolina: Dezvoltarea interfetei frontend folosind HTML, CSS si JavaScript.

## 3. Etapele implementarii

**Etapa 1 - Proiectare:**
- Stabilirea cerintelor aplicatiei.
- Definirea arhitecturii si a modelului de date.
- Realizarea schitelor interfetei.

**Etapa 2 - Dezvoltare:**
- Configurarea proiectului Spring Boot si a bazei de date.
- Implementarea interfetei frontend.
- Dezvoltarea REST API.
- Implementarea autentificarii si a rolurilor.

**Etapa 3 - Integrare:**
- Conectarea frontendului cu backendul.
- Implementarea functionalitatilor de inscriere si administrare.
- Adaugarea exportului CSV si a feedbackului.

**Etapa 4 - Testare si finalizare:**
- Testarea functionalitatilor principale.
- Verificarea securitatii si validarii datelor.
- Corectarea erorilor.
- Actualizarea documentatiei si pregatirea prezentarii.

## 4. Versionarea codului

Proiectul va fi gestionat prin Git si GitHub. Fiecare membru va contribui prin commituri proprii, 
iar modificarile vor fi integrate in branch-ul principal dupa verificare.

## 5. Riscuri si limitari

Un risc posibil este aparitia problemelor tehnice la integrarea frontendului cu backendul. 
Acestea pot fi reduse prin stabilirea din timp a API-urilor si testarea regulata a componentelor.
