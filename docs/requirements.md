
# Cerinte ale aplicatiei

## 1. Cerinte functionale

### Prioritate ridicata
- Inregistrarea si autentificarea utilizatorilor.
- Gestionarea rolurilor: Admin, Organizator si Participant.
- Crearea, vizualizarea, modificarea si stergerea evenimentelor.
- Inscrierea si retragerea participantilor la evenimente.
- Vizualizarea listei participantilor inscrisi.

### Prioritate medie
- Gestionarea agendei evenimentelor.
- Administrarea participantilor de catre organizatori.
- Exportul listelor de participanti in format CSV.

### Prioritate scazuta
- Colectarea feedbackului dupa evenimente.
- Vizualizarea feedbackului de catre organizatori.
- Gestionarea conturilor utilizatorilor de catre administrator.

## 2. Cerinte nonfunctionale

- Interfata intuitiva si usor de utilizat.
- Design responsive, adaptat dispozitivelor mobile si desktop.
- Securizarea conturilor si restrictionarea accesului in functie de rol.
- Validarea datelor introduse de utilizatori.
- Stocarea persistenta si corecta a informatiilor in baza de date.
- Tratarea erorilor si asigurarea functionarii corecte a aplicatiei.
- Protejarea datelor utilizatorilor impotriva accesului neautorizat.

## 3. Domeniul aplicatiei

Aplicatia include gestionarea evenimentelor academice, inscrierea participantilor, administrarea utilizatorilor, 
gestionarea agendei, colectarea feedbackului si exportul datelor in format CSV.

Nu sunt incluse procesarea platilor online, organizarea transportului sau integrarea cu platforme externe.
