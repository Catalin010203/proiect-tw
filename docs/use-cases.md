
# Use Cases - Academic Events

## 1. Crearea unui eveniment

**Utilizator:** Organizator

**Descriere:** Organizatorul se autentifica in aplicatie si acceseaza sectiunea de administrare a evenimentelor. 
Completeaza formularul cu titlul, descrierea, data, locatia si alte informatii necesare, apoi salveaza evenimentul.

**Rezultat asteptat:** Evenimentul este salvat in baza de date si devine vizibil participantilor.

## 2. Inscrierea la un eveniment

**Utilizator:** Participant

**Descriere:** Participantul acceseaza lista evenimentelor disponibile, selecteaza un eveniment si apasa butonul de inscriere.

**Rezultat asteptat:** Inscrierea este inregistrata in baza de date, iar participantul apare in lista persoanelor inscrise.

## 3. Gestionarea participantilor

**Utilizator:** Organizator

**Descriere:** Organizatorul acceseaza pagina unui eveniment si consulta lista participantilor inscrisi. Poate gestiona 
inscrierile si poate exporta lista participantilor in format CSV.

**Rezultat asteptat:** Organizatorul poate administra participantii si obtine un fisier CSV cu informatiile acestora.

## 4. Administrarea utilizatorilor

**Utilizator:** Administrator (Admin)

**Descriere:** Administratorul se autentifica si acceseaza sectiunea de administrare, unde poate consulta conturile 
utilizatorilor, modifica rolurile si gestiona accesul acestora.

**Rezultat asteptat:** Conturile si rolurile utilizatorilor sunt gestionate corespunzator, iar accesul la 
functionalitati este restrictionat in functie de rol.
